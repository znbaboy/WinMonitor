# WinMonitor 1.1.0

A small floating hardware monitor for Windows 11, with wireless device batteries built in.

**Install:** unzip `WinMonitor-portable-x64.zip` anywhere and run `WinMonitor.exe`. On 1.0.1 or later, install it from Settings > About > Check for updates.

## Look

- Settings redesigned on the latest WinUI 3 (Windows App SDK 2.7): Windows 11 title bar, sidebar with an app card, **Find a setting** search, roomier pages
- Cleaner panel: category name inside its card with a thin divider, quieter row names, thin bars under the values, rounder cards
- Monitor items: the category name lines up with its rows

## Categories and names

- Dashboard removed: Hostname, Time, Uptime and Local IP are now in Host
- New default row names: Clock, Usage, Temp, Voltage, AiO Speed, VRAM Use, GPU Fan, RAM Used, Case Fans (history still says CPU / GPU)

## New settings

- **Warning colours** (Alerts): untick any kind of value to keep it in the normal colour; replaces "Colour clock speeds"
- **Category spacing** (Panel): px between category cards

## Other

- Needs Windows 10 version 2004 or later (any Windows 11 PC)
- Download is about 63 MB

# WinMonitor 1.0.2

A small floating hardware monitor for Windows 11, with wireless device batteries built in.

**Install:** unzip `WinMonitor-portable-x64.zip` anywhere and run `WinMonitor.exe`. On 1.0.1, install it from Settings > About > Check for updates.

## Fixed in 1.0.2

- Custom names starting with an emoji were cleared after a restart
- A saved "Windows 11 Light" theme setting from 1.0.0 now opens as the Light theme
